## 🤖 AI Change Summary for PR #35

## 개요
이번 변경 사항은 방명록 서비스의 권한 검증 로직을 개선하고, 새로운 오류 코드를 추가하여 방명록 접근 권한을 보다 명확히 관리하도록 수정되었습니다. 또한, `guestBookRepository`의 메서드 호출을 수정하고 예외 처리 로직에서 반환되는 오류 코드를 업데이트하여 비즈니스 로직의 정확성을 향상시켰습니다.

## 주요 변경 사항
1. **오류 코드 추가**: `ErrorCode` 열거형에 `GUESTBOOK_ACCESS_DENIED` (403, "G003", "해당 방명록에 대한 권한이 없습니다.")가 추가되었습니다.
2. **메서드 호출 변경**: `guestBookRepository.findById` 메서드 호출을 `guestBookRepository.findByIdWithMember`로 변경하였습니다.
3. **메서드 주석 수정**: `updateGuestBook` 메서드의 주석이 "작성자만 가능"으로 수정되었고, `deleteGuestBook` 메서드의 주석이 "작성자나 상점 주인 가능"으로 변경되었습니다.
4. **권한 검증 메서드 변경**: `validateWriter` 메서드가 `validateDeletePermission`으로 변경되어, 방명록 삭제 시 작성자와 상점 주인 모두에게 권한을 부여하는 로직이 추가되었습니다.
5. **예외 처리 수정**: 예외 발생 시 반환되는 오류 코드가 `ErrorCode.NOT_GUESTBOOK_WRITER`에서 `ErrorCode.GUESTBOOK_ACCESS_DENIED`로 수정되었습니다.
6. **테스트 수정**: 방명록 삭제 권한 검증에 대한 테스트에서 오류 코드가 변경되었으며, 기존 테스트 케이스는 새로운 메서드 호출과 오류 코드에 맞게 업데이트되었습니다.

## 위험/영향
- 새로운 오류 코드 추가로 인해 기존의 오류 처리 로직에 영향을 줄 수 있으며, 방명록 접근 권한을 보다 세분화하여 관리할 수 있게 되었습니다.
- 권한 검증 로직의 변경으로 인해 방명록 삭제 시 권한이 없는 사용자가 삭제를 시도할 경우, 더 명확한 오류 메시지를 제공하게 됩니다.
- 변경된 메서드 호출로 인해 `guestBook`의 접근 권한 검증 로직이 강화되었으며, 오류 코드 변경으로 인해 클라이언트 측에서 처리하는 예외 로직이 영향을 받을 수 있습니다.
