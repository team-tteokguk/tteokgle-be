## 🤖 AI Change Summary for PR #38

### 개요
이번 변경 사항은 Spring Boot 애플리케이션에 Redis를 추가하고 JWT 기반 인증 시스템을 구현하기 위한 여러 설정을 포함합니다. 리프레시 토큰 관리 기능과 OAuth2 인증 성공 핸들러 수정이 포함되어 있으며, 관련된 클래스와 메서드가 수정되었습니다.

### 주요 변경 사항
1. **의존성 추가**: `build.gradle` 파일에 JWT 관련 라이브러리와 Redis 스타터 의존성이 추가되었습니다.
2. **Docker Compose 수정**: Redis 서비스가 추가되었으며, PostgreSQL 데이터베이스에 대한 주석이 수정되었습니다.
3. **Redis 설정 추가**: `RedisConfig` 클래스를 새로 생성하여 Redis 연결을 설정하는 Bean을 정의했습니다.
4. **보안 설정 수정**: `SecurityConfig` 클래스에서 JWT 인증 필터를 추가하고 CORS 설정을 포함했습니다. JWT 토큰을 통한 인증을 위한 URL 패턴이 추가되었습니다.
5. **Swagger 설정 수정**: Swagger API 문서에 JWT 인증 스키마를 추가하고 서버 URL을 설정했습니다.
6. **JWT 인증 필터 추가**: `JwtAuthenticationFilter` 클래스를 새로 생성하여 요청에서 JWT를 검증하고 사용자 인증을 처리합니다.
7. **리프레시 토큰 엔티티 추가**: `RefreshToken` 클래스를 새로 추가하여 리프레시 토큰을 Redis에 저장할 수 있도록 구현했습니다.
8. **JWT 토큰 제공자 수정**: `JwtTokenProvider` 클래스에 리프레시 토큰 생성 및 검증 메서드를 추가했습니다.
9. **리프레시 토큰 서비스 추가**: `RefreshTokenService` 클래스를 추가하여 리프레시 토큰의 저장, 삭제 및 유효성 검사를 담당합니다.
10. **인증 컨트롤러 수정**: `AuthController`에서 리프레시 토큰을 사용하여 새로운 액세스 토큰을 발급하는 로직을 구현했습니다.
11. **OAuth2SuccessHandler 수정**: 사용자 인증 성공 시 JWT 액세스 토큰과 리프레시 토큰을 생성하고, 리프레시 토큰을 Redis에 저장하는 로직을 추가했습니다.
12. **application.yml 수정**: Redis 데이터베이스 연결을 위한 호스트 및 포트 설정을 추가했습니다.

### 위험/영향
- **의존성 추가로 인한 충돌 가능성**: 새로운 라이브러리 추가로 인해 기존 의존성과의 충돌이 발생할 수 있습니다.
- **보안 설정 변경**: JWT 기반 인증으로 변경됨에 따라 기존 세션 기반 인증과의 호환성 문제가 발생할 수 있습니다. 특히, JWT 토큰을 URL 쿼리 파라미터로 전달하는 것은 보안 위험을 초래할 수 있습니다.
- **데이터 무결성**: 리프레시 토큰의 저장 및 삭제 과정에서 데이터 무결성이 유지되지 않을 경우 인증 관련 문제가 발생할 수 있습니다.
- **Redis 의존성**: Redis가 추가됨에 따라 애플리케이션의 배포 및 운영 환경에서 Redis 서버가 필요하며, 서버가 다운되거나 연결 문제가 발생할 경우 리프레시 토큰 저장이 실패할 수 있습니다.
